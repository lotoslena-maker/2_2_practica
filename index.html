НАВЧАЛЬНЕ ПИТАННЯ № 1

Основи збору даних через мережу Інтернет

Вебсайти публікують текст, таблиці, зображення та посилання у вигляді HTML-документів або завантажують дані з API. Аналітик не повинен вручну копіювати кожне повідомлення: він може автоматизувати отримання, відбір, структурування та перевірку відомостей.

Вебскрапінг (web scraping)

Програма завантажує HTML, знаходить потрібні елементи та вилучає з них значення: заголовки, дату, посилання чи вміст таблиці.

API (Application Programming Interface)

Програма звертається до документованої адреси сервісу та отримує готові структуровані дані, зазвичай у JSON.

Автоматизований збір — чотири кроки

GET-запит→HTML / JSON→Вилучення полів→Збереження результату

У PDF окремо розглянуто пасивний і активний збір та структуровані й неструктуровані дані. Важливе уточнення: навіть офіційний API-запит створює звернення до сервера і відповідний цифровий слід; це не «невидима» дія.

Структура вебсторінки: HTML, CSS, DOM

HTML — «скелет»

Теги задають зміст і структуру: <h2> — заголовок, <p> — абзац, <a> — посилання.

CSS — «оформлення»

Кольори, відступи та класи. CSS-селектор .news-title знаходить елемент із класом news-title.

DOM — «дерево об’єктів»

Браузер перетворює документ на дерево вузлів, яке може змінювати JavaScript.

JavaScript — «поведінка»

Обробляє натискання, запити до API й динамічне додавання вмісту без перезавантаження.

БАЗОВИЙ ІНСТРУМЕНТАРІЙ PYTHON

requests + BeautifulSoup: від HTML до таблиці

requests завантажує ресурс: надсилає HTTP-запити, читає код стану, заголовки, текст чи JSON. BeautifulSoup розбирає HTML і дозволяє шукати елементи за тегом, класом, id або CSS-селектором.

Встановлення у терміналі VS Code: python -m pip install requests beautifulsoup4. Пакет інсталюється як beautifulsoup4, а імпорт має вигляд from bs4 import BeautifulSoup.

Надсилаємо GET і перевіряємо відповідь

import requests

url = "https://example.com"
try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    print("Статус:", response.status_code)
    print("Тип:", response.headers.get("Content-Type"))
    print(response.text[:80])
except requests.RequestException as error:
    print("Помилка:", error)
Приклад очікуваного виводу (під час успішної відповіді): Статус: 200 Тип: text/html <!doctype html>...

timeout=10 обмежує очікування, raise_for_status() повідомляє про помилки HTTP 4xx/5xx, response.text повертає декодований текст, response.json() декодує JSON-відповідь. Приклад вище ілюстративний: фактичний вивід залежить від сервера.

Знаходимо теги та вилучаємо текст

from bs4 import BeautifulSoup

html = """
<article>
 <h3 class="news-title">Навчальний семінар</h3>
 <h3 class="news-title">Практикум Python</h3>
 <a href="/news/1">Докладніше</a>
</article>
"""
soup = BeautifulSoup(html, "html.parser")
titles = soup.select("h3.news-title")

for item in titles:
    print(item.get_text(strip=True))
print(soup.select_one("a").get("href"))
Навчальний семінар Практикум Python /news/1

select() повертає список вузлів за CSS-селектором; select_one() — перший збіг або None; get_text(strip=True) вилучає текст без крайніх пробілів; get("href") читає атрибут.

Відтворюваний приклад без Інтернету

from bs4 import BeautifulSoup
import csv

html = """<section>
<article class="item"><h3>Новина А</h3><time>2026-11-20</time></article>
<article class="item"><h3>Новина Б</h3><time>2026-11-21</time></article>
</section>"""

soup = BeautifulSoup(html, "html.parser")
rows = []
for article in soup.select("article.item"):
    rows.append({
        "title": article.select_one("h3").get_text(strip=True),
        "date": article.select_one("time").get_text(strip=True),
    })

with open("news.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "date"])
    writer.writeheader()
    writer.writerows(rows)
print(rows)

СУМІЖНІ ТЕХНІКИ

Динамічні сайти, Selenium та масштабний збір

Звичайний requests отримує первинну HTTP-відповідь, але не запускає JavaScript. Якщо сайт додає картки після завантаження сторінки, іноді потрібен браузерний інструмент. Перед цим варто перевірити, чи існує офіційний API.

Selenium керує справжнім браузером

Бібліотека запускає Chrome або Firefox, відкриває сторінку, очікує появу елементів у DOM і зчитує їхній текст. Вона корисна для JavaScript-сайтів, але споживає більше пам’яті й часу за звичайний HTTP-запит.

python -m pip install selenium
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# Безпечний локальний HTML-файл для вправи
from pathlib import Path
url = Path("demo_dynamic.html").resolve().as_uri()

driver = webdriver.Chrome()
try:
    driver.get(url)
    cards = WebDriverWait(driver, 10).until(
        EC.presence_of_all_elements_located(
            (By.CSS_SELECTOR, ".news-title")
        )
    )
    for card in cards:
        print(card.text)
finally:
    driver.quit()

  document.querySelector("#list").innerHTML =
   '<h3 class="news-title">Новина після JavaScript</h3>';
}, 700);

Новина після JavaScript

Ключова ідея: не використовувати фіксовану затримку sleep(), а очікувати потрібний елемент через WebDriverWait.

Scrapy — фреймворк для керованого збору

Scrapy підтримує чергу URL, обробники відповідей, повторні спроби, експорт результатів і налаштування навантаження. Він підходить для дозволених масштабних навчальних або дослідницьких задач.

python -m pip install scrapy
scrapy startproject lesson_scraper
import scrapy

class ExampleSpider(scrapy.Spider):
    name = "example"
    allowed_domains = ["example.com"]
    start_urls = ["https://example.com/"]

    custom_settings = {
        "ROBOTSTXT_OBEY": True,
        "DOWNLOAD_DELAY": 2,
        "CONCURRENT_REQUESTS_PER_DOMAIN": 1,
    }

    def parse(self, response):
        yield {"title": response.css("h1::text").get()}

Результат залежить від сторінки. Важливі налаштування: дотримання robots.txt, затримки й обмеження паралельності. Не намагайтеся обходити технічні заборони доступу.

СТРУКТУРОВАНИЙ ДОСТУП

API: програма розмовляє з програмою

API — узгоджений програмний інтерфейс із правилами доступу та форматом результатів. Endpoint — адреса конкретного ресурсу; параметри дозволяють фільтрувати, заголовки можуть передавати налаштування й авторизацію, а JSON містить структуровані поля.

Переваги API

Документована структура, менше зайвого HTML, зазвичай передбачуваніші версії та поля.

Обмеження API

Ліміти, ключі доступу, тарифи, дозвільні рівні й неповне охоплення даних.

JSON: пари «ключ — значення»

{
  "count": 2,
  "items": [
    {"id": 1, "title": "Семінар", "category": "education"},
    {"id": 2, "title": "Практикум", "category": "education"}
  ]
}

Python: робота з API

import requests

url = "https://api.example.org/news"  # УМОВНА адреса
params = {"category": "education", "limit": 2}
try:
    response = requests.get(url, params=params, timeout=10)
    response.raise_for_status()
    data = response.json()
    for item in data["items"]:
        print(item["title"])
except (requests.RequestException, ValueError, KeyError) as e:
    print("Не вдалося отримати дані:", e)

Цей URL вигаданий і не призначений для виконання. Для роботи із реальним API потрібна офіційна документація, чинна адреса та, за необхідності, авторизація. Не зберігайте API-токени у публічному репозиторії.

НАВЧАЛЬНЕ ПИТАННЯ № 2

Збір даних з використанням формалізованих документів

На відміну від пошуку на сторонніх сайтах, тут аналітик спочатку визначає набір полів та правила заповнення. Кожна відповідь має однакову структуру, тому простіше перевіряти повноту, будувати таблиці та формувати звіти.

Інформаційна потреба→Поля форми→Валідація→CSV→Аналітика

Проєктування форми — від мети до типів полів

Спочатку сформулюйте: яке рішення залежить від відповідей? Потім оберіть тільки необхідні поля. Для нашого прикладу — навчальний журнал технічного обслуговування умовних пристроїв.

Закриті питання дозволяють стандартизувати відповіді, відкриті додають контекст; шкали вимірюють оцінки, а умовна логіка показує додаткові поля лише за потреби.

Перевірка введення — захист від «сміття»

Обов’язкові поля, списки, числові межі, формат дати, зрозумілі підказки та повідомлення про помилки зменшують необхідність подальшого очищення. Валідацію потрібно виконувати і у браузері, і на сервері, якщо дані передаються на сервер.

Експорт і подальша обробка

Дані з форми можна зберегти в CSV для Excel, Python або бази даних. У Pandas корисні операції: read_csv, drop_duplicates, fillna, to_datetime.

import pandas as pd

df = pd.read_csv("records.csv", encoding="utf-8-sig")
df["date"] = pd.to_datetime(df["date"], errors="coerce")
df = df.drop_duplicates()
print(df.groupby("status")["quantity"].sum())
df.to_csv("clean_records.csv", index=False,
          encoding="utf-8-sig")
Приклад результату для навчальних даних: status ready 8 repair 3 Name: quantity, dtype: int64

Після очищення потрібен контроль: чи не видалено різні факти як «дублікати», чи не підмінено відсутні значення довільними.

Google Forms, власні сервіси та контроль даних

Google Forms або інші хмарні конструктори зручні для відкритих навчальних опитувань; для чутливої інформації потрібні дозволені організацією системи, контроль доступу, місця зберігання й журналювання. Варіанти власного розгортання — LimeSurvey, KoBoToolbox та інші спеціалізовані рішення.

QR-код — лише спосіб передати адресу форми, а не механізм захисту. Анонімність не можна гарантувати лише відсутністю поля «Ім’я»: платформа може зберігати технічні журнали.
