Структура проєкту та запуск у VS Code

Пояснення для слухачів, які вперше запускають Flask.

1. Що вміє застосунок?

Наочно показує, як вебсторінка взаємодіє з Python-сервером, як отримати HTML через мережу, вибрати з нього потрібні заголовки, сформувати JSON і відобразити таблицю.

Користувач→HTML / JavaScript→Flask→requests→BeautifulSoup→JSON / таблиця

2. Структура папок у VS Code

flask_demo/
├── app.py                 # Python + Flask + парсер
├── requirements.txt       # які бібліотеки встановити
├── sample_news.html       # локальна навчальна HTML-сторінка
├── .gitignore             # що не додавати у Git
├── templates/
│   └── index.html         # вигляд / зміст вебсторінки
└── static/
    ├── style.css          # кольори / розміщення
    └── app.js             # кнопки / вкладки / API / таблиця
Чому папки називаються саме templates і static?

Flask за замовчуванням шукає HTML-шаблони у templates, а статичні файли CSS та JavaScript — у static. Це домовленість фреймворку, тому вам не потрібно вручну налаштовувати шляхи для кожного файлу.

app.py · Flask

Створює Python-вебсервер, задає URL-маршрути /, /api/demo, /api/live. Повертає HTML або JSON.

app.py · requests

Створює HTTP GET-запит до сайту АрміяInform і отримує HTML-відповідь. Сам не вилучає заголовки.

app.py · BeautifulSoup

Розбирає HTML і шукає теги заголовків та посилання за CSS-селекторами. Сам не відкриває вебсайт.

templates/index.html · HTML

Описує видимі блоки сторінки: вкладки, кнопки, текст пояснення, таблицю й поля виводу.

static/style.css · CSS

Оформлює інтерфейс: кольори, шрифти, адаптивну сітку, картки та кнопки. Не завантажує інформацію.

static/app.js · JavaScript

Реагує на натискання кнопок, звертається до Flask через fetch() і заповнює таблицю результатами.

requirements.txt

Перелік бібліотек, які потрібно встановити командою pip install -r requirements.txt.

sample_news.html

Вигаданий навчальний HTML-документ. Дозволяє відпрацювати парсинг, навіть якщо Інтернету немає.

3. Запуск по кроках

КРОК 01

Завантажити код

У репозиторії lotoslena-maker/2_2_practica натиснути Code → Download ZIP, розпакувати. Або скористатися командою:

git clone https://github.com/lotoslena-maker/2_2_practica.git
КРОК 02

Відкрити папку у VS Code

У VS Code: File → Open Folder → 2_2_practica → flask_demo. У лівій панелі Explorer з'являться файли. Оберіть Terminal → New Terminal.

КРОК 03

Створити віртуальне середовище

Введіть у терміналі:

python -m venv .venv

Папка .venv містить окремий Python і встановлені пакети для цього проєкту. Її не потрібно завантажувати до GitHub.

КРОК 04 · WINDOWS

Встановити бібліотеки

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Для Ubuntu замість цього:

.venv/bin/python -m pip install -r requirements.txt
КРОК 05 · WINDOWS

Запустити Flask-сервер

.\.venv\Scripts\python.exe app.py

Для Ubuntu:

.venv/bin/python app.py

Очікуване повідомлення у терміналі: Running on http://127.0.0.1:5000. Термінал залишається запущеним, поки працює сервер.

КРОК 06

Відкрити браузер

Увести http://127.0.0.1:5000 на тому самому комп'ютері. Перейдіть на другу вкладку й натисніть Навчальний запуск.

КРОК 07

Зупинити сервер

Повернутися в термінал VS Code і натиснути Ctrl+C. Після зупинки сторінка за локальною адресою перестане обслуговувати нові запити.

Важливо: відкриття файлу templates/index.html подвійним клацанням не замінює запуску Flask. У шаблоні є конструкція url_for(...), яку обробляє сервер. Крім того, JavaScript звертається до локальних API-маршрутів Flask.

4. Як перевірити, що все працює?

Спочатку перейдіть за адресою http://127.0.0.1:5000/api/demo. Якщо Flask запущено, браузер відобразить JSON зі списком навчальних новин. Після цього перейдіть на головну сторінку й перевірте кнопки другої вкладки.

Flask — це сервер; HTML — структура; CSS — оформлення; JavaScript — взаємодія; requests — отримання HTML; BeautifulSoup — вилучення даних.
ДРУГА ВКЛАДКА

АрміяInform: як працює вебскрапінг і парсинг

Наочна демонстрація послідовності дій. Рекомендовано почати з локального навчального режиму.

1. Розмежовуємо поняття

Вебскрапінг

Організований процес отримання інформації з вебсторінки: звернення до ресурсу, отримання HTML, витяг полів і збереження.

Парсинг

Окрема частина процесу: програма розбирає HTML і вибирає потрібні теги та їхній текст або атрибути.

Flask приймає команду→requests завантажує→BeautifulSoup вилучає→JS показує

2. Оберіть режим

Живий режим виконує один добровільний HTTP-запит лише після перевірки robots.txt. Доступність і кількість результатів не гарантуються. Якщо сайт обмежує автоматизацію, використовуйте навчальний HTML.

ЕТАП 1 · FLASK

Приймаємо команду від браузера

JavaScript викликає fetch('/api/demo') або fetch('/api/live'). Flask визначає маршрут і викликає відповідну Python-функцію.

@app.get("/api/demo")
def demo():
    html = Path("sample_news.html").read_text(...)
    news = extract_news(html, SOURCE_URL)
    return jsonify({"articles": news})

ЕТАП 3 · BEAUTIFULSOUP
Парсимо: знаходимо заголовки та посилання
BeautifulSoup будує структуру HTML у пам'яті Python, шукає потрібні заголовки за селекторами, бере текст через get_text(), а адресу через атрибут href.
soup = BeautifulSoup(html, "html.parser")
for heading in soup.select(
    "article h2, article h3, h2.entry-title"
):
    a = heading.find("a", href=True)
    if a:
        title = heading.get_text(" ", strip=True)
        url = urljoin(SOURCE_URL, a["href"])

Чому парсер іноді не знаходить даних?
Теги та CSS-класи вебсайтів змінюються. Якщо requests повернув HTML, але BeautifulSoup не знайшов заголовків, це не завжди мережна помилка. Потрібно проаналізувати реальну HTML-структуру через DevTools браузера (F12) та оновити селектори. Не обходьте CAPTCHA, блокування та заборони.

Головні висновки
  1. Flask забезпечує зв'язок між браузером і Python: приймає запити, запускає логіку й повертає JSON.
  2. requests виконує HTTP-запит та отримує вміст вебсторінки, але не знає, який текст є заголовком новини.
  3. BeautifulSoup аналізує HTML та вилучає потрібні значення за селекторами — це парсинг.
  4. HTML, CSS і JavaScript разом формують користувацький інтерфейс: структура, оформлення та поведінка.
  5. Зібрані дані потрібно перевіряти, зберігати посилання на джерела й дотримуватися правил використання сайтів.


Контрольні запитання


Мініпрактика для слухача
  1. Запустіть проєкт у VS Code й відкрийте 127.0.0.1:5000.
  2. Виконайте локальний збір новин та покажіть HTML, JSON і таблицю.
  3. Знайдіть у коді місце, де використовується requests, і місце, де використовується BeautifulSoup.
  4. Змініть одну вигадану новину у sample_news.html, повторіть збір і перевірте, чи оновилася таблиця.
  5. Збережіть результат у CSV, відкрийте його в Excel та поясніть значення стовпців.
Очікуваний результат: слухач самостійно запускає Flask, пояснює призначення кожного файла і демонструє перетворення HTML → список словників → JSON → таблиця → CSV.
